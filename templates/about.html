About the System

AI Resume Screening System is a web-based application designed to help job seekers analyze their resumes and compare them with job descriptions.

ATS Resume Checker

The ATS Resume Checker analyzes a resume for ATS compatibility and identifies important areas such as formatting, readability, contact information, dates, and resume structure.

It also provides an ATS score and recommendations that can help users improve the clarity and compatibility of their resumes.

Job Description Matcher

The Job Description Matcher compares a resume with a specific job description to identify matching and missing skills.

It provides match percentage, resume similarity, ATS score, recommendations, and relevant learning resources based on the job description.

Purpose

The purpose of this system is to make resume analysis easier and more understandable for job seekers by presenting important resume information and job requirements in a simple format.

Technologies Used

Python • Flask • NLP • HTML • CSS • PDF Processing
